Feature Guide

Complete guide to Billy777 WhatsApp CRM — Cloud API Edition

1 Getting Started — Login & Dashboard

Login: Open the CRM link provided by your admin. Enter your username and password on the login page.

Dashboard: After login you'll land on the Team Inbox — your main workspace. The left sidebar has all navigation.

Connection Status: The bottom-left corner shows a green dot when WhatsApp Cloud API is connected and active.

Your Account: Your name appears in the top-right corner. Click the logout icon to sign out securely.

ℹ️ Note: This CRM uses the official WhatsApp Cloud API — no QR code scanning required. Your admin configures the API connection.

2 Team Inbox — Chat with Contacts

Chat List (Left Panel): Shows all conversations sorted by most recent. Each contact displays name, phone, last message preview, timestamp, unread count, and status badge.

Filter Tabs: Quickly filter by status — All Unread New Contacted Interested

Search: Use the search bar to find contacts by name, phone number, or message content.

Chat Panel: Click any contact to open the full conversation. Messages appear in real-time with WhatsApp-style bubbles.

Send Text: Type your message and press Enter or click Send. Max 4,096 characters per message.

Send Images: Click the 📷 camera icon → select a JPEG, PNG, or WebP image → optionally add a caption → click Send. Image preview shown before sending.

Quick Replies: Click the ⚡ bolt icon to reveal saved quick reply buttons — click any to send instantly.

Schedule Message: Click the 🕐 clock icon to schedule a message for a future date and time.

Status: Change a contact's stage from the dropdown in the chat header (New → Contacted → Interested → Sold).

Contact Info: Click the ℹ️ icon to open the detail panel — edit name, email, company, source, tags, notes, and revenue.

Real-time: New incoming messages appear instantly via real-time push — no need to refresh.

3 Media — Images, Videos & Voice

Send Images: In any chat, click the 📷 icon next to the message input. Select an image file (JPEG, PNG, or WebP, max 5MB). A preview bar appears — add an optional caption, then click Send.

Receive Images: Incoming photos display as thumbnails inside chat bubbles. Click any thumbnail to view it full-screen. Click anywhere or × to close.

Receive Videos: Incoming videos show a 🎥 Video placeholder. Video playback support coming soon.

Voice Messages: Incoming voice notes show a built-in audio player with play/pause, progress bar, and duration.

Chat List Preview: Media messages show clean previews — 📷 Photo, 🎥 Video, 🎤 Voice message — instead of raw brackets.

⚠️ Note: Media files are loaded securely through the server proxy — images are never exposed directly.

4 Contacts — Manage Your Database

Contacts Table: View all contacts with name, phone, status, source, tags, and last active time.

Stats Row: Quick overview — Total contacts, New, Contacted, Interested, and Sold counts.

Import CSV: Click "Import CSV" → paste data in format: phone,name,email,company,tags → Click Import.

Export CSV: Click "Export" to download all contacts as a CSV file for backup or external use.

Quick Navigate: Click any row to jump directly to that contact's chat in the Team Inbox.

5 Broadcasts — Bulk Messaging Campaigns

Create Campaign: Click "New Broadcast" → name your campaign, select audience (All, New, Contacted, Interested, or Sold), then write your message.

Send: Click the green Send button on a campaign card. Messages send with smart random delays between recipients to stay safe.

Track Progress: Each card shows real-time status — Draft, Sending, Completed, or Failed — with delivered/failed counts.

Delete: Remove any campaign by clicking Delete on its card.

⚠️ Best Practice: Keep broadcast groups under 500 contacts. Send relevant, personalized messages to maintain high delivery rates.

6 Automation — Auto-Reply Rules

Create Rule: Click "New Rule" → set a name, trigger type, priority, trigger value, and reply message.

Trigger Types:

  • Contains Keyword: Fires when a message contains any listed keyword (comma-separated).
  • Exact Match: Fires only when the message exactly matches the keyword.
  • First Message: Fires when a new contact sends their first-ever message — great for welcome messages.
  • Regex: Fires when the message matches a regular expression pattern — for advanced matching.

Priority: Higher number = fires first when multiple rules match the same message.

Toggle: Enable/disable any rule with the switch — no need to delete and recreate.

Performance: Rules are cached in memory for instant matching — no delay even with hundreds of rules.

7 Analytics — Dashboard & Insights

Stat Cards: Quick overview — Total Leads, New Leads, Sold, Messages Today, Incoming Today, and Total Revenue.

Lead Pipeline: Visual chart showing contacts at each stage — New, Contacted, Interested, Sold, Lost.

Message Trends: Chart of message volume over the last 7 days to track engagement.

Auto-Refresh: Data updates automatically — stay on the page and watch numbers change in real time.

8 Scheduled Messages — Send Later

Schedule: In any chat, click the 🕐 clock icon → write your message → pick date and time → click Schedule.

View All: The Scheduled page lists all pending messages with recipient, preview, and scheduled time.

Cancel: Click Cancel on any scheduled message before it's sent.

Auto-Send: The server checks every 30 seconds and automatically sends due messages.

Status: Messages show as pending → sent → or failed if delivery issues occur.

9 Quick Replies — Canned Responses

Create: Click "New Quick Reply" → set a title, shortcut (e.g. /welcome), and the reply text.

Use in Chat: In Team Inbox, click ⚡ to show quick reply buttons above the input. Click any to send immediately.

Manage: Edit or delete quick replies from the Quick Replies page.

Use Case: Perfect for frequently asked questions, greetings, follow-ups, and standard responses your team sends daily.

10 Settings

Connection Status: Shows whether your WhatsApp Cloud API is active — green dot means connected.

Theme: Click the 🌙 moon icon in the top bar to switch between Dark and Light mode.

Account Info: View your tenant name and server uptime.

API Config: Your admin manages the WhatsApp Cloud API credentials — Phone Number ID, Access Token, and Webhook setup.

💡 Tips, Security & Best Practices

Real-time Updates: Messages arrive instantly via server push. The chat list refreshes automatically — no manual reload needed.

Tags: Use comma-separated tags on contacts (e.g. "vip, premium, follow-up") for easy filtering and organization.

Revenue Tracking: Set revenue on Sold contacts to track total earnings in Analytics.

Combine Features: Use Auto-Reply for instant welcome messages + Broadcasts for follow-up campaigns = powerful automation.

Security: All connections are encrypted. The CRM includes rate limiting, content security headers, and secure session tokens. Your WhatsApp API credentials are never exposed to the browser.

Performance: Data is cached intelligently — the CRM stays fast even with thousands of contacts and 100+ users.

⚠️ Important: Never share your login credentials. Always log out when using a shared computer.
